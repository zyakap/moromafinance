# Moroma Finance Ltd

Whitelabelled **LoanMasta** tenant for Moroma Finance Ltd — "Your Local Finance
Partner", Port Moresby (Gordons) & Banz, Papua New Guinea.

- **Django settings module:** `moromafinance.settings`
- **Website:** `custom/templates/website/` (green `#0f6e3a` / gold `#f0a500`,
  stylesheet `static_files/custom/css/moroma.css`)
- **Brand assets:** `static_files/clientfiles/moroma_logo.svg`,
  `static_files/img/moroma_favicon.svg`, `static_files/clientfiles/brandlogo.png`
  (recreated from client artwork in `client_documents/`)
- **Configuration:** copy `.env.example` → `.env`
- **Deployment & go-live checklist:** see `DEPLOYMENT.md` (section 0 lists the
  tenant data that must be replaced before taking real applications)
